vibemon settings

Which accounts vibemon exec may run under, per project, in priority order. exec takes the first account in the list that is neither benched by a limit nor over the ceiling.

Accounts

A login (captured from Claude Code) gives usage numbers and interactive switching. A token from claude setup-token is what headless and per-project runs use; it lasts a year and cannot report usage. ChatGPT accounts are added with vibemon codex add and run under vibemon exec --kind codex; for them both columns mean the login in their own CODEX_HOME.

Default order: Claude

Used wherever no project matches. Untick to leave an account out of automatic picking.

    Default order: Codex

    The same for ChatGPT accounts: vibemon exec --kind codex fills them up in this order.

      Projects

      Longest matching path wins, so worktrees under a project inherit its accounts.
